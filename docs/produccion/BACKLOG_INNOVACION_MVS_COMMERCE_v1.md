# Backlog de Innovación MVS Commerce v1

Este backlog es **separado del cronograma de Producción**. Su función es conservar y priorizar ideas sin retrasar la salida de MYM.

## Regla

Primero se estabiliza MYM en Producción. Después se toman iniciativas del backlog según:
1. valor económico;
2. ahorro de trabajo;
3. reducción de errores/riesgo;
4. dificultad;
5. datos disponibles.

## Prioridad post-piloto

1. Dashboard inteligente “Qué requiere atención hoy”.
2. Reposición inteligente sugerida.
3. Transferencias inteligentes entre sucursales.
4. Predicción de quiebres de stock.
5. Centro de alertas inteligentes.
6. Recuperación automática de clientes.
7. Resumen ejecutivo automático.
8. ABC/XYZ y capital inmovilizado.
9. Atribución de ventas por vendedor.
10. WooCommerce ↔ MVS unificado.

Las acciones que afecten dinero, inventario, compras o precios siguen el principio:
**MVS recomienda y explica → humano aprueba → sistema ejecuta.**
